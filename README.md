# Геворк Бильярдинский v4.1 — Android TV / TCL 75″

Полноценный **проект для сборки APK**, не APK-файл. Основан на рабочей v4.0. Сохраняет русскую пирамиду, пул 8-ball, одиночный режим с компьютером, игру вдвоём, тренировку, физику, подсказки траекторий, паузу, фото Геворка и пульт Android TV.

## Мышь — новое в 4.1

- **Прицел**: просто ведите курсор по игровому полю. Кий плавно направляется к курсору, показывая обе траектории.
- **Выбрать бьющий шар в русском бильярде**: щёлкните на нужном шаре.
- **Сила и удар**: расположите курсор на свободной части сукна по направлению удара, нажмите и удерживайте **левую кнопку**, потяните мышь **обратно (против направления прицела)**. Шкала силы увеличится от 0 до 100%; отпустите кнопку, чтобы ударить. Прицел зафиксирован на всё время оттягивания. Короткий щелчок без оттягивания не стреляет — защита от случайных ударов.
- **Вращение**: нажимайте **− / 0 / +** под столом: оттяжка / без вращения / накат. Это сделано кнопками, потому что Android TV может не поддерживать колесо мыши.
- **Чёрная восьмёрка**: когда игра попросит заказать лузу, просто щёлкните по нужной лузе.
- **Свободный биток после штрафа**: щёлкните по свободному месту, затем **«Подтвердить биток»** внизу экрана.
- **Меню / Пауза**: выбирайте кнопки мышкой; в игре есть видимая кнопка «Ⅱ Пауза».

### Две мыши через USB-хаб

USB-хаб может позволить физически подключить две мыши к одному USB-порту. **Однако стандартный Android TV обычно использует один системный курсор**: отдельного курсора для каждого игрока не будет. Зато обоими устройствами можно управлять им по очереди — каждый в свой ход. Это зависит от конкретного TCL и хаба. Не обещаем независимые курсоры.

### Пульт остаётся рабочим

- `← / →` — точная пошаговая регулировка угла; удержание — быстрое вращение.
- `↑ / ↓` — в пуле накат / оттяжка; в русском короткое — выбор бьющего шара, удержание — вращение.
- `OK` держать — набрать силу, отпустить — удар.
- `Назад` — пауза. Во время набора силы угол удара неизменен.

Можно менять мышь на пульт и обратно в одной партии. Вдвоём можно играть и одной мышью.

## Музыка 4.1

Сохранены прежние четыре мелодии. Добавлены **три оригинальных более ритмичных инструментальных джазовых лупа** без заимствования известной музыки:

- `lobby-swing.mp3` — Лобби-свинг (по умолчанию), около 50 с
- `city-jazz.mp3` — Городской джаз, около 54 с
- `club-groove.mp3` — Клубный грув, около 47 с

Списки музыкальных треков и эффекты настраиваются отдельно. **Исправлено отображение:** статус «● ИГРАЕТ / ○ ВЫКЛЮЧЕНА» показывает текущую настройку, не название действия. Музыка может проигрываться в меню и настройках (после пользовательского действия, необходимого для разрешения звука браузером/Android).

## Тренировка

Новые сценарии: **тонкая резка**, **дальний точный удар**, **удар через борт**. При создании используется случайная геометрия и проверяется реальной симуляцией игрового стола. Успех → новое задание. Промах → тот же расклад. Если система не нашла бортовой удар за разумное число попыток, подставляет проверенную сложную резку (чтобы интерфейс не зависал).

Тренировка рассчитана на настоящий челлендж, но точность и динамика остаются моделью 2D-физики, а не спортивным симулятором.

## Как собрать APK через GitHub

1. Загрузите **содержимое ZIP**, не сам ZIP, в корень репозитория GitHub. Файлы `build.gradle`, `settings.gradle`, `gradle.properties` должны быть в корне, папка `app` рядом с ними.
2. **GitHub Actions** запускает сборку после загрузки/Commit, если каталог `.github/workflows` также загрузился.
3. Если скрытая `.github` не загрузилась в Chrome на Mac: **Add file → Create new file**, введите `.github/workflows/build-apk.yml`, вставьте содержимое видимого файла `ГОТОВЫЙ_BUILD_APK_YML.txt` и нажмите **Commit changes**.
4. Откройте вкладку **Actions**, дождитесь зелёной галочки и скачайте **Artifacts → Gevork-Billiardinsky-v4.1-APK**. Внутри будет `app-debug.apk`.

Репозиторий должен содержать именно файлы новой версии: при загрузке поверх старых устаревшие файлы с другими названиями остаются. Лучше использовать новый пустой репозиторий, либо аккуратно заменить каталог `app`.

В версии 4.1 установлен `versionCode=6`, `versionName=4.1`. Если установленный на TCL APK подписан другим ключом, Android может потребовать удаление предыдущей версии — это может удалить локальные сохранения.

## Проверки и ограничения

- `node --check`: синтаксис JavaScript проходит.
- В браузере Chromium проверены выбор режима, управление мышью в русском, выбор шара, прицел, оттягивание и удар, кнопки накат/оттяжка, меню звука, пауза, режим восьмёрки.
- Генерация случайных задач: тестировались сценарии резки, дальних ударов и бортовых ударов; симуляция не пропускает непроверенные расклады.
- MP3 файлы автономные, без интернета. Управление пультом осталось прежним.
- **APK в этом окружении не собирался, физический TCL не тестировался**. Особенности конкретной мыши, USB-хаба и Android WebView требуется проверить на телевизоре. Невозможно обещать отсутствие ошибок на неизвестной модели TCL.

Без рекламы, телеметрии, аккаунтов и внешних API.
